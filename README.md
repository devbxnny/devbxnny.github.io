# devbxnny portfolio

A responsive static portfolio built with HTML and CSS.

## Open in VS Code

Extract the ZIP, then choose File → Open Folder and select devbxnny-portfolio.
Open index.html in your browser, or use the VS Code Live Server extension.
No installation or build step is needed.

## Files

- index.html — page content, project entries, and links
- styles.css — colors, typography, layout, and mobile styles

## Publish with GitHub Pages

Upload index.html, styles.css, README.md, and .gitignore to the root of your portfolio repository.
In the repository settings, open Pages and choose Deploy from a branch, main, / (root).
